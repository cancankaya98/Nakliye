# Nakliye Maliyet Hesaplama

Nakliye işleri için maliyet hesaplayan tek dosyalık web uygulaması (`index.html`).

Sırayla sorulanlar: yakıt litre fiyatı, yol (km), taşıma personeli sayısı, personel kişi başı ücret.
Araç ayarlarından yakıt tüketimi (L/100 km) ve amortisman bedeli (TL/km) girilir. Dönüş yolu seçeneği km'yi iki katına çıkarır.

Çalıştırmak için `index.html` dosyasını tarayıcıda açmak yeterlidir.
